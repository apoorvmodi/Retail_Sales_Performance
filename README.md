# 📊 Retail Sales Performance & Dashboard (Excel + VBA)

An interactive Excel workbook and macro-enabled reporting suite analyzing sales, profitability, discount patterns, and regional performance across the US Superstore dataset.

---

## 📌 Project Overview
This workbook provides interactive reporting and automated analysis for **9,994 retail transactions**. By leveraging **Pivot Tables, dynamic Pivot Charts, and VBA Macros**, the file allows users to explore sales trends across categories, customer segments, and geographic regions.

---

## 🚀 Key Features

- **Automated Workflow (VBA Macro-Enabled):**
  - Includes custom automation routines (`vbaProject.bin`) to streamline data refresh, dashboard navigation, and report generation.
- **Interactive Pivot Tables & Charts:**
  - Multi-dimensional breakdown of sales and profit across **Region, Category, Sub-Category, and Customer Segment**.
  - Dynamic visual summaries using bar charts, line charts, and pie charts.
- **Detailed Data Model:**
  - Complete underlying dataset with standard fields: `Order Date`, `Ship Mode`, `Segment`, `Region`, `Product Name`, `Sales`, `Quantity`, `Discount`, and `Profit`.

---

## 📈 Analytical Highlights

- **Top Revenue Categories:** High sales volume driven primarily by **Technology** and **Office Furniture**.
- **Customer Segmentation:** Core revenue dominated by the **Consumer Segment** (~50%), followed by **Corporate** and **Home Office**.
- **Discount & Profit Dynamics:** Pinpoints low-margin and loss-making states and sub-categories caused by heavy discounting strategies.
